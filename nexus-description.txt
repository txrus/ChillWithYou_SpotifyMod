A Spotify player inside Chill with You: Lo-Fi Story.

Play, pause and skip, shuffle and repeat, control the volume, and drag
the progress bar to seek. See what's playing with its cover art, search
for songs, artists, albums and playlists, browse an artist's albums,
open your own playlists or your Liked Songs, and switch playback to
another device - all from the pause menu, without alt-tabbing out.


=== NEW IN v1.5 =====================================================

* No building. This download is a ready-made DLL now.

  Until now the mod needed your Spotify Client ID compiled into it,
  which meant installing the .NET SDK and building from source just to
  paste in one line. Several of you told me that was where you gave up,
  and fair enough.

  The Client ID now goes in a text file instead:

      BepInEx\config\com.pw_txr.spotifyplayer.cfg

  Drop in the DLLs, run the game once, paste your ID into that file,
  restart. No .NET SDK, no GameDir.props, no C#.

* If you forget the Client ID, the panel tells you so when you press
  Connect, instead of opening a browser page that could only fail.

Earlier, in v1.4:

* Shuffle and repeat buttons next to the transport controls. Hover
  either one to see its name - the icons alone are too small to read.
* A volume slider sits next to the buttons too.
* A Devices button shows every device Spotify sees and lets you switch
  playback to one of them - no more "nothing happens" when Spotify has
  no active device.
* Hover the progress bar to preview the time you're about to seek to,
  before you click.
* Long playlists no longer lose track of what's playing once you're
  past the first 21 songs.
* A "Liked Songs" row in My Lists plays your saved tracks from the top,
  same as any playlist - and you can click a specific track in the
  queue to jump straight to it.

Earlier, in v1.3:

* Change the song on your phone, or in the Spotify app on the same PC,
  and the panel catches up within a few seconds. It only checks while
  the panel is open - close the menu and it stops entirely.
* Drag or click the progress bar to jump to a spot in the song.


=== ALREADY RUNNING AN OLDER VERSION? ===============================

Your old DLL had the Client ID baked inside it. This one doesn't, so
you do need to put your ID in the config file - it's the one extra step
for upgraders, and after that you never touch it again.

1. Copy both DLLs from this download over the old ones in
   BepInEx\plugins.
2. Launch the game once, then close it.
3. Open BepInEx\config\com.pw_txr.spotifyplayer.cfg and paste the same
   Client ID you were building with.

Your saved login survives the upgrade. You will not have to approve
anything in the browser again.


=== BEFORE YOU START ================================================

You need:

* Spotify Premium. Spotify only allows playback control (play / pause /
  skip) on Premium accounts. Free accounts can log in but cannot
  control anything.
* Windows. Your login is saved encrypted with Windows DPAPI.
* BepInEx 5.x (x64).
* A free Spotify developer app - yours, not mine. Spotify ties the
  permission prompt and the usage limits to whoever registered the app,
  so it can't be shipped with the mod. Making one takes two minutes and
  is step 2 below.

That's the whole list. No .NET SDK and no compiler since v1.5.


=== 1. INSTALL BEPINEX AND THE MOD ==================================

1. Download BepInEx 5.x (x64):
   https://github.com/BepInEx/BepInEx/releases

2. Extract it into your game folder, next to "Chill With You.exe".

   To find that folder in Steam: right-click the game > Manage >
   Browse local files.

3. Launch the game once, then close it. BepInEx creates its folders on
   that first run, including BepInEx\plugins.

4. Extract this download and copy BOTH files into BepInEx\plugins:

       ChillWithYou_SpotifyMod.dll
       System.Security.Cryptography.ProtectedData.dll

   The second one encrypts your saved login. Without it, Spotify login
   fails right after you approve in the browser.


=== 2. CREATE YOUR SPOTIFY APP ======================================

Free, about two minutes. The mod talks to Spotify through their
official Web API, which requires an app registration. Yours is private.

1. Go to https://developer.spotify.com/dashboard and log in.

2. Click "Create app". Name and description can be anything.

3. In "Redirect URIs", enter this EXACTLY, including the trailing
   slash:

       http://127.0.0.1:8901/callback/

4. Under "Which API/SDKs are you planning to use?", tick "Web API".

5. Save, then open the app's Settings page and copy the Client ID -
   a 32-character string of letters and numbers.

You only need the Client ID. You do NOT need the Client Secret: this
mod uses PKCE, which is designed for apps that cannot keep a secret.


=== 3. PASTE YOUR CLIENT ID INTO THE CONFIG FILE ====================

1. Launch the game once with the mod installed, then close it. That
   first run creates the config file:

       BepInEx\config\com.pw_txr.spotifyplayer.cfg

2. Open it in any text editor (Notepad is fine). Find:

       [Spotify]
       ClientId =

3. Paste your Client ID after the "=", with no quotes:

       [Spotify]
       ClientId = a1b2c3d4e5f6...

4. Save and close the file.

The mod reads this once when the game starts, so edit it with the game
closed - or restart the game after editing.


=== 4. PLAY ========================================================

1. Start Spotify on the same PC and play anything, so Spotify has an
   active device to control.

2. Launch the game. The Spotify panel is in the pause / settings menu.

3. Click "Connect Spotify". Your browser opens Spotify's permission
   page - approve it, then go back to the game.

You only log in once. The session is remembered and resumes next time.


=== IF SOMETHING GOES WRONG =========================================

The panel says "no Spotify Client ID set"

  The config file is empty, or the ID didn't save. Check that you
  edited BepInEx\config\com.pw_txr.spotifyplayer.cfg inside your GAME
  folder, that the line reads ClientId = yourid with no quotes, and
  that you restarted the game after saving.

I pasted the ID but the mod still doesn't see it

  The file is read only at startup, so the game must be restarted. If
  you edited it while the game was running, the game may also have
  written its own copy back over yours on exit - close the game first,
  then edit.

There's no config file in BepInEx\config

  The mod isn't loading at all. Check that both DLLs are in
  BepInEx\plugins, and that BepInEx itself is installed correctly -
  BepInEx\LogOutput.log should exist after a run.

Browser opens but login never completes

  Two usual causes. First, the Redirect URI in your Spotify app must be
  exactly http://127.0.0.1:8901/callback/ - http (not https), and the
  trailing slash matters. Second,
  System.Security.Cryptography.ProtectedData.dll must sit in
  BepInEx\plugins next to ChillWithYou_SpotifyMod.dll.

  You can confirm the second one: the player log will mention
  "Could not load file or assembly ... ProtectedData". It's at
  %USERPROFILE%\AppData\LocalLow\nestopi\Chill With You\Player.log

Buttons do nothing, playback won't change

  Playback control needs Spotify Premium, and Spotify needs an active
  device. Make sure Spotify is open and playing on the same PC.

Nothing appears in game

  Check BepInEx\LogOutput.log for lines tagged [Spotify Player Mod].
  Feel free to post that log in the Bugs tab - it says which Client ID
  the mod picked up, partly hidden, so it's safe to paste.


=== WHAT SPOTIFY WON'T LET THE MOD DO ===============================

Spotify removed a number of Web API endpoints for apps like this one,
so a few things are simply not possible:

* An artist's top tracks. Their album list does work - that's what
  expands when you click an artist - but "most popular songs" doesn't.

* Picking a specific track while playing from an artist. The queue is
  display-only there; use the next button.

* Reading the track list of most playlists, including Daily Mix,
  Discover Weekly and "This Is ..." - so clicking a playlist plays it
  rather than opening it. Once it starts, the real queue shows up.

* Long result lists. Search returns at most 10 per category, and an
  artist's albums come back 10 at a time (the mod pages through up to
  50 for you).

* Saving/liking a song, or browsing the full list of your Liked Songs.
  The endpoint for reading or writing that list returns an error in
  this app's mode, confirmed and not fixable in code. You can still
  play Liked Songs from My Lists in the panel - it just can't be
  browsed track-by-track before you do.

Full details and links to Spotify's announcements are in the README.
